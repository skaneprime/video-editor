# Video Editor

A simple React-based video editor for experimenting with various video editing libraries and capabilities.

## Current Status

This is an experimental project exploring different video editing libraries and approaches. Please note:

- Basic video rendering functionality is implemented
- Audio compilation is currently not working and under development
- UI components and controls are being actively developed
- This is not production-ready code

## Getting Started

1. Clone the repository
2. Install dependencies: `pnpm i`
3. Launch dev `pnpm dev`
